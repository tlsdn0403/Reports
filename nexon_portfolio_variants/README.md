# 넥슨용 포트폴리오 HTML 후보 5안

`index.html`을 열면 다섯 디자인을 비교할 수 있습니다. 모든 후보는 기존 Canva의 앞부분과 마무리를 동일하게 사용하고, FlickDom 상세 13–17페이지만 다르게 디자인했습니다.

- `candidate-01.html`: CANVA CONTINUITY — 기존 Canva 연장형
- `candidate-02.html`: SYSTEM BLUEPRINT — 네트워크 기술형
- `candidate-03.html`: PLAYABLE SCENE — 시네마틱 결과형
- `candidate-04.html`: CODE REVIEW — 기술 매거진형
- `candidate-05.html`: FLICK BOARD — FlickDom 개성형

## 페이지 구성

- 01–03: 기존 Canva 그대로.
- 04: 감염: 죽음의 도시 소개를 PDF형 프로젝트 정보표로 변경하고 GitHub·YouTube 아이콘을 연결했습니다.
- 05–06: 기존 Canva 그대로. 졸업작품 영상 2개도 원본 MP4로 재생됩니다.
- 12: FlickDom 소개를 PDF형 프로젝트 정보표로 변경하고 GitHub·YouTube 아이콘을 연결했습니다.
- 13–17: 친구 포트폴리오의 FlickDom 게임 소개·접속 흐름·AI 활용을 바탕으로 새로 구성했습니다.
- 18: 기존 Canva 감사 페이지 그대로.

## 합친 기준

- 현재 Canva 포트폴리오의 프로젝트 순서, 어두운 넥슨용 톤, Infection 중심 흐름을 유지했습니다.
- 임찬진 포트폴리오의 FlickDom 게임 목표·조작·멀티플레이 소개를 보강했습니다.
- 팀 기여를 섞지 않도록 박신우 범위는 `Board / Card Pattern / Stage / Turn FSM / Network 구조 수정 / WebGL Build`로 구분했습니다.
- 초기 Host/Client 기반, Drag/Flick 입력, 게임 규칙·사운드는 임찬진 담당으로 별도 표기했습니다.
- Art/Material/UI는 황인성 담당으로 별도 표기했습니다.
