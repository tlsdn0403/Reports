08
Technical Case 01

BoneName 기반
좀비 부위 피격

문제

총알이 Mesh가 아니라 Capsule Collision에 먼저 맞아 BoneName이 None으로 들어왔습니다.

해결

총알-캡슐 충돌 채널을 분리하고 Mesh 피격 기준으로 FHitResult를 전달했습니다.

검증

BoneName으로 부위 내구도를 찾고, 팔/다리 파괴와 StartCrawling 전환까지 연결했습니다.

Host 권위 턴 검증

Client Input → FlickRequest / PlacementRequest → Host Validation → Host Simulation → PhysicsSettled → Snapshot Broadcast

클라이언트 입력을 바로 결과로 확정하지 않고, Host가 요청을 검증한 뒤 물리 결과와 보드 상태를 확정하도록 구성했습니다.

Technical Case 05

Snapshot과 Client Prediction

문제

WebGL 멀티플레이에서 조작 반응성과 Host 결과 정합성이 충돌할 수 있었습니다.

구현

BoardState, ScoreState, CardState Snapshot으로 결과를 공유하고, 클라이언트는 예측 후 보정했습니다.

검증

Stage별 카드 배분, 보드 점령, 점수 계산이 클라이언트마다 일치하는지 확인했습니다.
